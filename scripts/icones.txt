# icones.txt — o conjunto de ícones que entra no pacote.
#
# Fonte dos desenhos: lucide (ISC), pinado em lucide-static@0.575.0 — a MESMA
# minor que o console e a PWA consomem via lucide-react (DS-03). Os dados de
# path são EMBUTIDOS por scripts/gerar-icones.mjs; o pacote lucide não é
# carregado em runtime e não vai para o dist. Ver NOTICE.md.
#
# Os nomes são os CANÔNICOS do lucide. Alias depreciado do lucide-react (ex.:
# AlertTriangle) resolve para o canônico (triangle-alert) — mesma geometria,
# nome que sobrevive. Não há alias antigo do ppl-compass: nome errado quebra.
#
# Para acrescentar um ícone: some o nome canônico aqui e rode `npm run icones`.
# Nome inexistente na biblioteca REPROVA a geração — não há erro silencioso.
